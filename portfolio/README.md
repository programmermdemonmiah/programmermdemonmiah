# MD. Emon Miah — Portfolio

Responsive portfolio built with Next.js App Router, React, TypeScript, and custom CSS. Uses Yarn.

## Local development
1. Open this folder: `cd portfolio`
2. Install: `yarn install`
3. Run: `yarn dev`
4. Production build: `yarn build`

## Deploy on Vercel
Import this repository in Vercel and set **Root Directory** to `portfolio`. Select Next.js and use `yarn install` and `yarn build`.
